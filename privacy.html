Hermes Boxy – Privacy policy

Last updated: November 22, 2026

Hermes Boxy is a personal assistant that Nate Nugent runs on his own home computer for his own Google account. It is not offered to the public, and no one else can sign in to it.

What it accesses

With the owner's permission, Hermes Boxy uses Google APIs to read and organize the owner's Gmail, draft and send email when the owner asks, read and update the owner's Google Calendar, read and save files in the owner's Google Drive, and read names from the owner's Google Contacts.

How the data is used and stored

  • Data is used only to provide these features to the owner.
  • The sign-in token and any working copies are stored only on the owner's computer.
  • Data is not sold, shared with third parties, or used for advertising.
  • Google user data is not used to develop, improve or train generalized AI or machine-learning models.

Google API Services User Data Policy

Hermes Boxy's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions, which stops all access immediately.
